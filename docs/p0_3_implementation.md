# P0-3 单人整轮流程

2026-09-07，Godot 4.7.2。默认入口为 `run/run_arena.tscn`。原训练靶与 Boss 对练场景保留，可从编辑器单独运行。

## 用户修改

- 翻滚起身收势从 0.15 秒改为 **0.05 秒**。滚动 0.55 秒及无敌区间 0.08–0.28 秒保持不变。
- 针对 Boss 出现在角色头上的反馈：双方实体碰撞改为平直侧面的圆柱，Boss 各动作阶段按世界地面校正高度，不把角色头部作为地面。用户原现场没有直接复现；模拟离地后的攻击恢复及 60 秒贴身突进/翻滚回归通过，Boss 最大脚底高度约 0.001m。仅适用于本阶段无跳跃平地 Boss。
- 原 Excel 已更新当前规格、参数、开发状态、自动验收及用户缺陷反馈。真人镜头复验和轻重取舍仍保留未测，未虚填试玩时长或结果。

## 流程与操作

| 状态 | 行为 |
| --- | --- |
| 准备 | 一把大剑、恢复药和精力饮料；生命精力全满，两次复活；可自由准备，Boss 不受伤也不攻击。 |
| 战斗 | Enter 或开始按钮进入 180 秒挑战；开场 1 秒安全缓冲；八边禁出边界阻挡行走、翻滚。 |
| 倒地 | 前两次各扣一次复活，1.2 秒后在距离 Boss 最远的安全点复起。Boss 保留残血，时钟继续。 |
| 复起 | 50% 生命、满精力、清除移动惯性，2 秒保护；主动攻击提前结束保护。第三次倒地失败。 |
| 胜利 | 同步关闭伤害与 Boss AI、停止时钟和新空投、解除禁出，只生成一个中央两格箱。 |
| 搜刮 | 无限时走到外围，拾取原有物品和空投，使用/替换道具，反复存取箱子。 |
| 结束确认 | 展示随身未装箱清单与地面物资数量，可取消。确认后仅保存箱内清单，舍弃其他物品，展示结果。 |
| 失败 | 超时或复活耗尽，停止伤害/AI/空投；无胜利箱。结果记录战斗用时、受击、倒地与已用复活。 |

- E：拾取最近物品；靠近中央箱时打开箱子。
- 1 / 2：使用对应道具。恢复药 +30 生命、饮料 +50 精力；上限钳制，已满不消耗。
- Shift+1 / Shift+2：满栏时将附近道具换入指定栏，旧物留在地面。拾取另一把大剑会交换唯一武器栏，旧剑落地。
- Enter：准备时开始；搜刮时打开结束确认。R 仅在准备/结果阶段开始新一轮。
- Esc：暂停；暂停菜单重开也有确认，确认期间战斗保持暂停。
- F9：搜刮阶段保存箱内快照。F10：提示清空当前物品并还原快照，需确认，不刷新本轮复活或计时。

空投每 18–28 秒随机一次，最多三件。合法点半径 3–8m，1.5 秒预告后落地；已经预告的空投可在胜利后完成落地。三个外围静态物资点位于场地半径 13m。整个场地保持平地，外侧边界仍限制在场景内。

## 数据与范围

`RunSession` 管理整轮状态与计时，`RunInventory` 管理一武器、两道具和两格箱的唯一归属，`RunItem` 保存稳定实例 UID 与类型。相同来源和本轮拾取物使用相同存取逻辑。

`user://p0_chest_snapshot.json` 只保存箱内版本化清单。读取前校验类型、容量与 UID 去重，失败不修改当前物品。成功还原清除额外随身/地面物品，不消耗或刷新复活，不开启下一只 Boss。`user://p0_last_result.json` 保存本轮结果。测试脚本使用独立的 `test_output` 文件，不覆盖玩家快照。

P0 采用“仅箱内进入测试快照”的解释，不等于建立跨轮永久装备仓库。未实现第二只 Boss、多人、外围控场支援、赌约、金币或永久成长。
